# Stage 4b and 4c on Kaggle

Kernels generated by `build_kernels.py` from [`../../stage4b_push.ipynb`](../../stage4b_push.ipynb) (`dr-s4b-*`) and [`../../stage4c_push.ipynb`](../../stage4c_push.ipynb) (`dr-s4c-*`). Run them in order; kernels on the same line can run at the same time. Each takes the outputs of the line above as inputs.

| Kernel | Work | Time (T4) |
|---|---|---|
| `dr-s4b-k0-quick` | quick test of the full pipeline; downloads and caches the images | ~25 min |
| `dr-s4b-k1-s42`, `dr-s4b-k1-s43` | Block 1, one seed each (6 runs) | ~1.5 h each |
| `dr-s4b-k2-a`, `dr-s4b-k2-b` | Block 1 adoption; Block 2, two candidates each | ~1 h each |
| `dr-s4b-k3-top1`, `dr-s4b-k3-top2` | Block 3, 5-fold CV of one top candidate each | ~2–3 h each |
| `dr-s4b-k4-final` | no training; opens the test set once, final tables | minutes |

## Stage 4c ([plan](../../stage4c_plan.md))

`k4-final` is not run: `dr-s4c-c2-final` opens the test set once for Stage 4b (section 11) and Stage 4c (section 13) together.

| Kernel | Work | Inputs |
|---|---|---|
| `dr-s4c-c0-quick` | quick test of every Stage 4c path; memory/speed probe at full size | `k3-top1`, `k3-top2`, EyePACS |
| `dr-s4c-c1-ab`, `dr-s4c-c1-b2c`, `dr-s4c-c1-x` | arms A + B; B2 + C; EyePACS pre-training + X | `k3-top1`, `k3-top2` (+ EyePACS for `c1-x`) |
| `dr-s4c-c2-final` | no training; Part 0 and both final tables | the three `c1` kernels, `dr-stage4-outputs` |

EyePACS = Kaggle dataset `tanlikesmath/diabetic-retinopathy-resized` (2015 training images, cropped and resized). `dr-stage4-outputs` is a private dataset with the six Stage 4 Colab `outputs.npz` files.

```bash
python build_kernels.py <kaggle username> 4b   # or 4c; regenerate after editing the notebook
kaggle kernels push -p dr-s4b-k0-quick         # needs Kaggle CLI >= 2.0 for the T4 machine shape
kaggle kernels output <user>/dr-s4b-k4-final -p out   # final CSVs and figures in out/dr-grading/stage4b/
```

If a kernel stops at the time guard, push it again with its own output added as an input; finished runs are never retrained.
